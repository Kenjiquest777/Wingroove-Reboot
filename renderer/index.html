    About WinGroove Reboot

    WinGroove Reboot v1.0.0

    A from-scratch tribute to the classic WinGroove software wavetable MIDI player for Windows 95/98.

    Features: Echoing software reverb, dynamic sound leveler/compressor, 16-channel live instrument window, and offline WAV rendering.

    Put a file named WinGroove.sf2 in soundfonts/ to use it as the default bank.
