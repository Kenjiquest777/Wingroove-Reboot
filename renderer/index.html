    About WinGroove Reboot

    WinGroove Reboot v1.0.0

    A from-scratch tribute to the classic WinGroove software wavetable MIDI player for Windows 95/98.

    Engine: SoundFont 2 synth on Web Audio with reverb, compressor, 16 channels, WAV export.

    Put a file named WinGroove.sf2 in renderer/soundfonts/ to use it as the default bank.
