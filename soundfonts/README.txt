WinGroove Reboot - SoundFonts Directory
=========================================

Place your .sf2 SoundFont files in this folder.

Default SoundFont:
- If a file named "WinGroove.sf2" is present here, the app loads it automatically on startup.
- You can switch SoundFonts at any time via the SoundFont button in the app or by dragging and dropping any .sf2 file into the player window.

Original SoundFont:
- The default packaged fallback is TimGM6mb.sf2.
- If you have an authentic WinGroove 4MB / 2MB SoundFont rip, rename it to "WinGroove.sf2" and place it here.
